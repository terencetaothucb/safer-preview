# Encrypted preview

This repository contains an encrypted static preview and its browser-based viewer. Project content and images are stored only in the encrypted payload. A complete sharing link is needed to decrypt the preview. The decryption key is not stored in this repository.

GitHub Pages: publish the root of the main branch. Enforce HTTPS. Do not add plaintext source files, key files, or sharing links to this repository.

Possession of the complete link grants access. Forwarded links also grant access; there is no per-person revocation. Previously downloaded encrypted copies can still be decrypted by anyone who retained their original key. Keep the hosting account secure, since it controls the viewer code.
